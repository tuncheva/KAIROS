KAIROS · Design proposal · docs/ui

The AI widget, reduced to the ask

The floating assistant currently carries six pieces of chrome before a single word of the answer: a grip, a sparkle, a title, an agent stamp, three window buttons and a resize glyph. This proposal keeps every capability and removes the decoration around it — one hairline surface, one accent, and text that starts at the top of the panel instead of a third of the way down it.

03 — The edit

What is removed, and what replaces it

Nothing here removes a capability. Drag, resize, minimise, agent choice, scope choice and the escape hatch to /chat/ai all survive; they simply stop announcing themselves.

05 — Build order

Four commits, no migration

  1. Title bar. Rewrite the header in A1ChatWidgetOverlay.tsx: drop the grip and sparkle, replace the inline shadow and border with kairos-menu-surface, move minimise onto a double-click handler, delete the resize glyph, and add the clear-conversation button — rendered only when the thread has messages, and asking for confirmation inline in the bar rather than in a dialog.
  2. Byline. Move the agent label out of the header and into the answer byline that ProjectIntelligenceChat already renders on the page variant — the widget stops hiding it rather than growing a new element.
  3. Composer. Restyle the two ComposerMenu triggers as text chips, keeping the accent tone for the agent picker only, and hold the send button at rest until the field has text.
  4. Empty state. Suggestions from cards to rows in the isPanel branch, and the list from four down to three.

All four are contained to the widget path — the full page at /chat/ai is untouched, so the two surfaces can be compared side by side before the same reduction is proposed for the page.
