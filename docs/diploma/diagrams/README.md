# Диаграми на дипломната

Всяка фигура от дипломната е **текстов Mermaid файл** в `src/`. Редактирате текста, харнесът проверява диаграмата спрямо кода и я слага на мястото ѝ в `.docx`.

| Файл | Какво е |
|---|---|
| `diagrams.yaml` | коя диаграма е коя фигура, надпис, допълнителни проверки |
| `src/*.mmd` | изходният код на диаграмите – **редактирайте тези** |
| `mermaid.json` | общ стил (шрифт, цветове), за да изглеждат еднакво |
| `out/*.svg`, `out/*.png` | генерирани изображения – не се редактират на ръка |

## Как да редактирам диаграма

1. Отворете `src/<диаграма>.mmd`:
   - във **VS Code** с разширението *Markdown Preview Mermaid Support* или *Mermaid Chart* – прегледът се обновява, докато пишете;
   - или копирайте съдържанието в **https://mermaid.live**, редактирайте там и го върнете обратно.
2. Пуснете проверките и рендерирането (от корена на репото):

   ```bash
   python thesis-harness/run.py diagrams scan
   ```

3. В Claude Code кажете „провери диаграмите“ – агентът проверява и смислово, предлага поправки, вие одобрявате на страницата за преглед.
4. „Сложи диаграмите в дипломната“ → всяко изображение влиза на мястото на фигурата си като предложение за одобрение (`diagrams to-doc`, после `apply`).

Кратък синтаксис: `A --> B` стрелка, `A -->|текст| B` стрелка с надпис, `A["текст<br>втори ред"]` кутия, `subgraph Име ... end` група, `%%` коментар. Пълно ръководство: https://mermaid.js.org/intro/

## Какво се проверява автоматично

- рендерира ли се (синтаксис);
- всяка фигура от дипломната има диаграма, надписът съвпада, фигурата е спомената в текста;
- агентите са с имената си, не A1–A6;
- числата (таблици, миграции, рутери, езици, агенти) отговарят на кода;
- ER диаграмата: таблици, колони и връзки съществуват в `src/server/db/schemas`;
- обзорът на домейните съдържа всички таблици точно веднъж;
- Site Map: всеки път съществува в `src/app` и всяка страница е показана;
- имената от кода (функции, колони, файлове) съществуват.

Отделно Claude преглежда всяка диаграма спрямо кода и текста на дипломната (`thesis-harness/prompts/diagram-accuracy.md`).
